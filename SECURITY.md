## Reporting a Vulnerability

We take the security of `scaffzap` seriously. If you discover a security vulnerability within this project, please do not disclose it publicly in an issue or on social media. 

Instead, please report it securely via one of the following methods:

1. **GitHub Private Vulnerability Reporting:** Go to the "Security" tab of this repository, select "Advisories," and click "Report a vulnerability."
2. **Email:** Send a detailed report to [sabtainalipk144@gmail.com].

Please include the following information in your report:
* The type of vulnerability (e.g., Prototype Pollution, Command Injection).
* The steps required to reproduce the vulnerability.
* The expected behavior and the actual behavior.
* The version of `scaffzap` and Node.js you are using.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress. If a vulnerability is confirmed, we will release a patch as soon as possible and publish a security advisory to notify users.
